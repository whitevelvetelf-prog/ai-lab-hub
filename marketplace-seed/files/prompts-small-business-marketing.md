# 12 промптів для маркетингу малого бізнесу

Версія 1.0 · AI LAB HUB · Ліцензія CC BY 4.0 (використовуйте й змінюйте з посиланням на AI LAB HUB)

## Як користуватися

1. Замініть `{змінні у фігурних дужках}` власними даними.
2. Чим точніші вхідні дані, тим кориснішим буде результат. Не просіть модель «придумати» факти про ваш бізнес: давайте їй свої.
3. Перевіряйте результат. Імена, цифри, обіцянки й гарантії модель може вигадати (див. чекліст перевірки відповідей AI).
4. Набір працює з будь-яким чат-асистентом.

### Універсальна преамбула

Додайте її на початку розмови один раз:

```
Ти — досвідчений маркетолог для малого бізнесу в Україні. Пиши простою, живою мовою без канцеляриту. Не вигадуй фактів, цін і відгуків. Якщо даних бракує, спочатку постав мені до 5 уточнювальних питань.
```

---

## 1. Портрет клієнта

Коли: ви не впевнені, кому саме продаєте.

```
Мій бізнес: {що продаєте і кому зараз}.
Дані про поточних клієнтів: {віковий діапазон, місто, як знаходять нас, типові запитання}.
Склади 3 портрети клієнтів. Для кожного: хто це, яку проблему вирішує, що заважає купити, якими словами говорить, де проводить час онлайн.
Познач, що є припущенням, а що випливає з моїх даних.
```

## 2. Унікальна торговельна пропозиція

Коли: потрібне коротке пояснення, чому обирають вас.

```
Продукт або послуга: {опис}. Ціновий діапазон: {діапазон}.
Конкуренти: {2–3 назви і чим відомі}.
Чим ми реально відрізняємось: {перелік фактів}.
Запропонуй 5 формулювань пропозиції по 1–2 речення. Використовуй лише факти, які я навів.
Для кожного варіанта напиши, кому він сподобається найбільше.
```

## 3. Контент-план

Коли: потрібен план публікацій на місяць.

```
Склади контент-план на {4 тижні} для {Instagram / Telegram / LinkedIn}.
Бізнес: {опис}. Цілі: {цілі}. Частота: {N} постів на тиждень.
Рубрики мають чергуватися: користь, довіра (закулісся, кейси), продаж, залучення.
Виведи таблицю: дата, рубрика, тема, формат, заклик до дії.
```

## 4. Пост із нотаток

Коли: є думки або факти, але немає готового тексту.

```
Ось мої сирі нотатки: {текст}.
Перетвори їх на пост для {платформа}, до {800} знаків. Тон: {дружній / експертний}.
Перший рядок має зацікавлювати. Наприкінці один чіткий заклик до дії: {дія}.
Дай 2 варіанти.
```

## 5. Email-розсилка

Коли: потрібен лист із чіткою метою.

```
Напиши розсилку. Мета: {мета}. Аудиторія: {хто}.
Пропозиція: {що і на яких умовах, з датою завершення, якщо є}.
Дай 5 варіантів теми листа (до 50 знаків), прехедер і текст до 150 слів з однією кнопкою-закликом.
```

## 6. Відповідь на негативний відгук

Коли: клієнт публічно скаржиться.

```
Клієнт залишив відгук: «{текст відгуку}».
Факти про ситуацію з нашого боку: {факти}.
Що ми готові запропонувати: {рішення або компенсація}.
Напиши спокійну публічну відповідь до 100 слів: визнай проблему, не беручи на себе провини там, де факти невідомі; поясни наступний крок; запроси до приватної розмови. Без сарказму й виправдань.
```

## 7. Опис товару

Коли: карточка товару без тексту.

```
Товар: {назва}. Характеристики: {список}. Для кого: {хто}.
Напиши опис до 120 слів: перша фраза про вигоду, далі 3–5 пунктів з характеристик і того, що вони дають клієнту.
Не додавай характеристик, яких немає в списку.
```

## 8. Тексти для реклами

Коли: запуск оголошень у Google Ads або Meta.

```
Напиши 5 варіантів рекламного оголошення для {Google Ads / Meta}: заголовок до 30 знаків, опис до 90 знаків.
Пропозиція: {…}. Ключові слова або інтереси: {…}.
Уникай перебільшень, слів «найкращий» і «№1» без підтвердження.
```

## 9. Редактор

Коли: текст є, але він важкий.

```
Відредагуй цей текст для {аудиторія}: {текст}.
Завдання: скороти на 20%, спрости складні речення, прибери канцелярит і повтори. Збережи зміст і всі факти.
Покажи результат і окремим списком, що саме ти змінив.
```

## 10. Заголовки

Коли: потрібні варіанти назви для статті, сторінки чи відео.

```
Дай 15 заголовків для {статті / сторінки / відео} про {тема}.
Групи: 5 інформативних, 5 з цифрою, 5 з інтригою.
Уникай клікбейту, який не виправдовується змістом.
```

## 11. FAQ для сайту

Коли: клієнти ставлять одні й ті самі питання.

```
Ось питання, які нам ставлять: {список}.
Ось наші умови: {доставка, оплата, повернення, години роботи}.
Склади розділ FAQ для сайту: чіткі відповіді до 50 слів кожна.
Якщо в умовах немає відповіді, познач [потрібне уточнення] замість вигадування.
```

## 12. Аналіз конкурентів

Коли: потрібно зрозуміти, де ви можете виділитися.

```
Ось публічна інформація про конкурентів, яку я зібрав: {тексти з сайтів, ціни, відгуки}.
Проаналізуй лише цей матеріал: як вони позиціонуються, які обіцянки дають, про що мовчать, де є можливості для нас.
Не додавай відомостей про ці компанії зі своєї пам'яті.
```

## Що робити з результатом

- Прочитайте текст уголос і замініть фрази, яких ви б ніколи не сказали.
- Перевірте кожну цифру, назву, дату й обіцянку.
- Не публікуйте чужі персональні дані та комерційну інформацію в промптах, якщо не впевнені в умовах сервісу.
