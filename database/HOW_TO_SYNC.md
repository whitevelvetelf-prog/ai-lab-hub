# Синхронізація локальної бази з хостингом

Хостинг-БД: `gu621051_ailabhublive`. Три сценарії — обирай за тим, що змінилося.

---

## 1. Публікація НОВИХ ПРОДУКТІВ (не зміни коду)

Відкрити `database/increment_latest.sql`, скопіювати весь текст, вставити
в phpMyAdmin хостингу → вкладка **SQL** → **Вперёд**.

Ніякого архіву й ніякого видалення таблиць не потрібно.

- Файл містить лише `INSERT` для продуктів останньої доданої партії
  (`products`, `product_categories`, `product_subcategories`,
  `pricing_plans`).
- Усі запити — `INSERT IGNORE`: повторний імпорт нічого не дублює й не
  затирає, рядки з наявними id просто пропускаються.
- Файл перезаписується щоразу після наступної партії продуктів — завжди
  бери його свіжу версію.

---

## 2. Зміни коду (PHP / шаблони / ассети)

Зібрати архів і залити його на хостинг:

```
powershell -ExecutionPolicy Bypass -File scripts/build-deploy.ps1
```

Отриманий `deploy5.zip` розпакувати в корінь сайту на хостингу
(перезаписати файли). Конфіги (`config/*.php`) в архів не входять — вони
налаштовані на сервері окремо.

---

## 3. Перше наповнення порожньої бази хостингу

Одноразово, коли БД на хостингу створена, але порожня:
`database/export_live_full.sql` → phpMyAdmin → вкладка **SQL** → **Вперёд**.
Містить структуру + дані всіх таблиць, без `CREATE DATABASE` / `USE`.
