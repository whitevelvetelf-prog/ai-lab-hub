# database/batches — копії партій продуктів

- **`2026-09-21-manual-batches-safe.sql`** — ЄДИНИЙ актуальний файл усіх ручних партій (69 продуктів, 136 тарифів,
  14 прив'язок наявних продуктів, виправлення SEO). Без фіксованих id: `WHERE NOT EXISTS` за нормалізованим URL + `@pid`.
  Його й треба заливати на хостинг.
- **`2026-09-21-autofill-imagen.sql`** — партія автозаповнення (tools/autofill), теж без фіксованих id.
- Файли `2026-09-20-*.sql` та `2026-09-21-dim-2.sql` — **застарілі** окремі партії **з фіксованими id** (історія й
  джерело тексту). Не виконувати на хостингу: якщо там id 618+ зайняті іншими продуктами, продукт мовчки
  пропускається, а його прив'язки й тарифи чіпляються до чужого продукту (перевірено симуляцією 2026-09-21).

Порядок заливки й перевірки — у `database/HOSTING_UPLOAD.md`. Нові партії робити лише в безпечному форматі.
