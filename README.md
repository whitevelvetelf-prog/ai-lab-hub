# AI LAB HUB

Веб-застосунок на PHP — хаб для експериментів та інструментів у сфері AI.

## Структура проєкту

| Папка        | Призначення                                  |
|--------------|----------------------------------------------|
| `public/`    | Точка входу (`index.php`), публічні ассети    |
| `app/`       | Бізнес-логіка застосунку                      |
| `config/`    | Файли конфігурації                           |
| `database/`  | Міграції, сіди, схема БД                     |

## Запуск (локально)

```bash
php -S localhost:8000 -t public
```

Далі відкрити http://localhost:8000 — має вивестись `AI LAB HUB — new project OK`.

## Оточення

Змінні оточення зберігаються у `.env` (не додається до git). За зразок можна
створити `.env.example`.
